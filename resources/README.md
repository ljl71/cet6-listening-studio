# 资料来源目录

`catalog.json`记录本机整理的27套资料的考试时间、公开来源页面、音频时长/字节数/SHA-256及候选质量状态。它不包含完整试题、原文、译文或音频。

`reference-sources.json`另列原文对照网页、原版PDF的来源页面/目录、原始文件名、大小和校验值，方便按来源核对自己的资料；原始文件本身不在仓库内。

资料原件包括真题录音、第三方PDF、网页快照、来源译文和解析。目前没有确认允许在此公开仓库再分发这些原件的授权，因此不随源码上传。项目采集记录中的“本机个人学习、不打包公开传播”是本机整理采用的范围，不能当作来源授予的公开许可证。网站能公开访问，也不能据此推定允许重新打包发布。

在新电脑上使用，可在真题库点击“一键获取真题资料”，主动从受支持的公开来源获取音频、题目和原文，自动入库；仍需遵守来源条件，遇到访问限制或加密即停止。获取后的答案和逐句时间保留待校对状态，不等同于本机经过多轮整理的版本。安装和启动时不会未经点击自动下载。

也可以导入自己有权使用的试卷JSON和音频，或者私下恢复自己的完整资料备份。

如以后取得允许公开再分发的授权，可以单独整理资料包，注明授权来源、适用范围、版本和校验值；源码仓库继续保留个人记录隔离。
